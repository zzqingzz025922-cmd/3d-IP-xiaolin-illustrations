# IP 关键词结构与特征分级

这是本技能维护角色一致性的描述规则，不是行业统一定级，也不是模型数值权重。用户明确要求变更时优先执行，并说明哪些识别特征随之改变。

## 识别短语

小林：**齐刘海红圈高马尾女生**。

展开：近黑深棕头发、厚齐刘海、鲜红发圈、高位波浪马尾的大头女生。识别短语概括默认造型，方便检索，不取代脸部身份；选择披发变体后仍然是小林。

通用结构：**角色名称 + 轮廓特征 + 标志性细节**。

例如本角色为“小林 + 齐刘海高马尾 + 红发圈”。若一个词不够区分，就用简短组合，不强求单个词具有唯一性。名称是技能内的索引，不假设图像工具仅凭名字已认识角色；生成时仍需描述和参考图。

## 外形拆分与定级

| 等级 | 部位或属性 | 小林关键词 | 变化规则 |
|---|---|---|---|
| P0 核心身份 | 比例与脸部轮廓 | 大头小身体、圆润脸颊、明显耳廓、小鼻小嘴 | 普通换装、换动作时锁定，以参考图为准，不编造比例数值 |
| P0 核心身份 | 面部结构 | 深棕大眼、浓密上睫毛、厚齐刘海、脸侧短发束 | 锁定相对位置与基本形状；表情允许眼皮和嘴形合理变化 |
| P0 核心身份 | 面部与发色 | 近黑深棕发、桃色皮肤、暖粉腮红、细雀斑、粉色眼妆 | 保持参考图颜色与分布，避免换脸或肤色漂移 |
| P1 标志造型 | 外轮廓与配饰 | 高位波浪马尾、红发圈、银色圈耳环 | 默认保留；认可的披发、帽子或用户明确指定可覆盖 |
| P2 场景造型 | 服装与其他配件 | 基础装、通勤装、街头装等 | 可替换，锁定 P0；不把某套服装当成永久身份 |
| P2 场景状态 | 表情、动作、视线、道具 | 疲惫、高兴、挤压、搬运等 | 随主题变化；局部编辑时按用户要求锁定 |
| S 画风 | 材质、光照、色彩、背景 | 3D 黏土潮玩、柔光、白底、自然桃肤、深发层次 | 按画风参考校准；独立于身份与服装 |

## 标准 prompt 的组成

**参考图职责 + 身份识别 + P0 固定项 + P1 造型选择 + P2 服装/动作/表情 + S 画风 + 构图 + 保留项/排除项**。

最短调用可写：

> 用小林（齐刘海红圈高马尾女生）为【主题】生成配图，穿【服装】，正在【动作】，表情【情绪】。保持参考图的脸与比例，使用已确认的白底 3D 黏土画风。

实际工具调用仍使用 [完整模板](prompt-template.md)，并实际传入参考图。

## 可复用中文模板

```text
参考图：A 用于角色身份；B 用于已选服装（可选）；C 用于已确认画风。
各图只约束指定职责，不复制参考的姿势、道具和场景。

角色名称：【IP 名称】
识别短语：【轮廓特征 + 标志性细节】

P0 固定身份：【头身比例、脸型、五官、基础发型、颜色及面部标记】。
保持身份参考中的相对位置与外形，表情变化不等于换脸。
P1 本次标志造型：【默认造型，或明确选定的认可变体】。
P2 本次服装：【上装、下装、鞋、必要配件】。

主题：【要解释的概念】。
核心意思：【一句话】。
动作与物件：【角色通过什么具体动作表达核心意思】。
表情与视线：【情绪、看向哪里】。

S 画风：匹配画风参考的 3D 黏土潮玩渲染，圆润雕塑体块、细腻皮肤、
发丝与适度布料细节；柔和棚拍光，少量接触阴影。
明度与饱和度参考确认图，保留自然肤色、深发与深衣层次，不自动全局加亮加饱和。

构图：【默认 16:9 横版、一个角色、少量道具、纯白背景、大量留白、安全边距】。
文字：【默认无文字；需要时逐字列出短标注】。
保留项：【本轮不应改变的内容】。
排除项：无无关角色、水印、品牌字样、参考图版式、额外肢体或意外裁切。
```
