# 构图与原创隐喻

## 没有主题时

用户要求生成但只说“小林 IP”时，使用 02 的全身站姿提包造型和默认穿搭，交付透明 PNG。不要强行发明隐喻、道具或动作。

## 从明确主题形成画面

1. 找出一个核心认知，如“负担过重”“杂乱变有序”“信任逐步建立”。
2. 转成一个直观物理动作，如扛、分拣、搭建、修补、搬运。
3. 选少量物件，让角色通过动作解释概念。物件可拟物、简化，保持合理受力、接触和空间关系。

## 按需选择构图

| 结构 | 适用场景 | 表达方式 |
|---|---|---|
| 单一隐喻 | 抽象判断、痛点 | 一个角色、一组道具、一个动作，默认优先 |
| 前后对比 | 混乱到有序、困难到顺畅 | 两个清楚分离的状态，保持同一角色 |
| 简短流程 | 输入、处理、输出 | 用摆放与动作形成方向，箭头仅在必要时添加 |
| 分层搭建 | 方法、能力积累 | 少量可见体块，角色直接参与搭建 |
| 路径或小分镜 | 学习过程、状态变化 | 少量节点或 2–4 个场景，每个只表达一个动作 |

默认透明背景；只有用户明确要白底或场景时添加背景。单幅图默认一个角色。只有对比或分镜需要时才在不同区域重复同一角色，并保持外形一致。

参考图用于身份和画风校准，不是固定构图模板。信息方块和受压姿势只在主题适合时使用；不同主题重新选择物件与动作。道具数量由表达需要决定，不把一次示例的方块数量固定为通用规则。
