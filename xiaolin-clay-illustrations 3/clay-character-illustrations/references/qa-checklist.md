# 小林验收清单

- 默认主参考是 02 提包全身图。仅指定“小林 IP”的生成结果是全身站姿提包，不附加主题或额外道具。
- 身份符合参考：厚齐刘海、近黑深棕高马尾、红发圈、深棕眼睛、粉色眼妆、自然桃肤、雀斑、银色圈耳环和头身比例；明确的变体要求除外。
- 未指定换装时为白衬衫、深蓝近黑针织马甲、黑裙、乳白罗纹袜、黑色系带鞋和黑色小手包，没有回退到三视图的 T 恤、短裤、短靴。
- 主题可改变动作与表情；不能因主题自动换衣。认可的披发、帽子或其他服装只在被选定时使用。
- 默认生成是带真实 Alpha 的 PNG，检查到透明背景像素和可见、接近不透明的主体；无白底、浅桃底、黑底或画入的棋盘格。不将 PNG 后缀或 RGBA 模式本身当作透明证明。
- 马尾、手包、鞋子没有裁切；轮廓和包把、耳环空隙无明显底色残边，白衬衫和白袜没有误被抠除，无地板、底座或投影雾。
- 用户明确指定白底或场景时使用指定背景；局部编辑未擅自改变目标原有透明度。
- 渲染为已认可的 3D 黏土材质与柔光，肤色自然、暗部有层次，无无故全局加亮加饱和。
- 实际传入适用参考，12 仅校准画风，不复制灯泡、动作或疲惫表情；不复制海报文字和版式。
- 手指、肢体、包与道具接触正常；有主题时一图一意，需要的短标注准确。

失败时只针对相关项修正。工具无法产生真透明时明确报告，不交付不透明图却宣称是透明素材。
