## 选择

默认传 02 锁定身份、通勤服装、小包与默认站姿，并按需传 [12 已确认画风](../assets/examples/12-approved-clay-style.png) 校准白底黏土渲染。12 来自本次“灵感枯竭”通勤换装版，由用户确认画风满意；它只约束渲染，不把灯泡动作、疲惫表情和白底设为通用默认。默认提包服装由 02 明确规定。

表情明显时可加 01；换装时选对应造型图。02 约束默认身份与提包穿搭，03 只辅助角度和比例，明确选定的变体图可覆盖服装或发型，12 约束渲染，提示词明确各自职责。

需要道具配色时可加一张相关海报，只参考颜色和质感。通常共 1–3 张足够，不机械加载全部图片。

局部改色以成图为编辑目标，按需要增加一张小林参考；目标图锁定构图，参考图提供颜色锚点。
