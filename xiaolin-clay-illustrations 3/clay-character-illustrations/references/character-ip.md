# 小林 IP 与默认造型

正式名称：小林。默认身份、全身站姿和穿搭以 [02 提包全身图](../assets/character/02-office.png) 为准。用户最新提供的同一张图确认了该默认设定。生成请求只说“小林 IP”时也使用此造型。

## 固定身份

- 大头小身体的潮玩女生比例，圆润脸颊、明显耳廓、小鼻子和微翘小嘴。
- 深棕大眼、浓密上睫毛、粉色眼妆、桃色皮肤、暖粉腮红与鼻颊细雀斑。
- 近黑深棕头发、厚而整齐的齐刘海、脸侧短发束；默认高位波浪马尾和鲜红发圈。
- 默认银色圈形耳环。普通换装、换动作保持脸型、五官位置和头身比例。

## 默认提包通勤造型

“黑色套装”按参考图具体展开为：白色翻领长袖衬衫、深蓝近黑色 V 领针织马甲与小金色纽扣、黑色裙子、乳白色罗纹袜、黑色系带鞋，单手提黑色小手包。不要把白衬衫和深蓝马甲全部涂成纯黑，也不要改成西装裤、T 恤、牛仔短裤或厚底短靴。

未给主题、动作或表情时：全身正面站立，参考图中的自然半垂眼神与平静微嘟嘴，一只手提包，另一手自然下垂。只出现一个小林，不新增灯泡等主题道具。

有主题但未指定服装时仍保持上述穿搭和包；动作可随主题改变。双手需要操作道具时，可将包自然放在身边，不把包错误融入手掌或人物身体。明确换装、配件或动作要求优先于默认。

## 已有变体与参考边界

用户已提供街头、粉色休闲、红色套装、黑白搭配、居家装及原三视图服装。只有明确指定或明确要求按场景换装时才切换，不因主题随意换衣。披发、帽子等按选定造型图执行，仍保持齐刘海与面部身份。

[01 表情图](../assets/character/01-expressions.png) 辅助情绪；[03 三视图](../assets/character/03-turnaround.png) 只辅助前侧背比例与发型，不能覆盖默认提包穿搭。参考图片自身的浅桃底不属于默认造型，生成时忽略背景。
