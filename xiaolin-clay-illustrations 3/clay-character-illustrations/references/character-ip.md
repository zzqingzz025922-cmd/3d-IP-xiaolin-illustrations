# 小林 IP

正式名称：小林。基础身份以 [三视图](../assets/character/03-turnaround.png) 为主，[表情图](../assets/character/01-expressions.png) 辅助核对五官与情绪。其他造型见 [参考图索引](reference-index.md)。

默认识别短语：**齐刘海红圈高马尾女生**。按 [关键词与分级](ip-keywords.md) 区分核心身份、标志造型、场景造型和画风；短语不是图像模型自动认识的独有触发词。

## 固定识别特征

- 大头小身体的潮玩女生比例，圆润脸颊、明显耳廓、小鼻子与微翘小嘴。
- 深棕色大眼睛、浓密上睫毛、粉色眼妆、桃色皮肤、暖粉腮红与鼻颊部细雀斑。半垂眼皮是常见神态，表情可随主题改变。
- 近黑色深棕头发、厚而整齐的齐刘海、脸侧短发束。默认高位波浪马尾、鲜红发圈。
- 银色圈形耳环是常规识别配饰；不沿用上一版角色的蓝眼睛、侧扫刘海、发夹或垂坠蝴蝶耳饰。
- 换装保持脸型、五官位置和头身比例，不变成另一个人。

## 基础装与变体

未指定服装时采用三视图的深灰短袖 T 恤、卷边牛仔短裤、深色厚底短靴，不增加旧角色的夸张破洞或靴子鞋带。

已提供的其他造型均属小林：通勤学院装、街头装、粉色休闲装、红色套装、黑白搭配、居家装。按用户指定或明确场景选一套，保持主要单品；无明显依据时用基础装，不随机混搭。服装品牌文字不属于固定身份特征。

高马尾是默认发型。红色套装、黑白搭配、居家装图中的披发和帽子是已认可变体；使用时保留齐刘海、发色和面部身份，不强行添加马尾，也不把正常造型变化判为漂移。

## 表情与动作

高兴、悲伤、生气、惊讶参考表情图，保留同一张脸，不自动写出表情标签。姿势、视线和情绪服务主题，不把疲惫固定为唯一神态。

让小林承担概念动作，如搬、扛、分拣、搭建、推、接、整理、修补。保持正常肢体与合理受力，不把身体变成抽象道具，不放在角落充当无关装饰。
